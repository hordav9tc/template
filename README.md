# Template weboldal projekt

Készítette: Horváth Dávid
Osztály: 9TC szakma 1

## Téma

A weboldalam témája: Iron Maiden

## Template

Ezt a W3.CSS template-et választottam: Band Template

Azért választottam, mert: A Band template eléggé jól illeszkedik egy zenekar bemutatásához

## Mit módosítottam?

- Font Awesome iconok módosítása
- Top bar szinezés, stílus
- Logó beíllesztése a "carousel" alá
- Bandáról leírás
- Merch, keresés gomb, jegyek és elérés törlése

## Használt technológiák

- HTML
- CSS
- W3.CSS
- GitHub Pages
